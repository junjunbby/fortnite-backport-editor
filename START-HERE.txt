Fortnite Backport Editor
========================

To start the local PC app:

1. Double-click:
   Start Backport Editor.cmd

2. A normal app window opens automatically.

3. If you want to stop the background server later, double-click:
   Stop Backport Editor.cmd

Optional:
Double-click Create Desktop Shortcut.cmd to put the app on your desktop.

This is not meant to be used as a browser tab.
